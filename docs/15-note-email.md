# 수업 기록 이메일 보내기

## 처음 한 번 — 팀의 발송용 Gmail 설정

1. 소리봄 전용 Gmail 계정을 준비하고 2단계 인증을 켭니다.
2. [Google 앱 비밀번호 안내](https://support.google.com/accounts/answer/185833?hl=ko)에 따라 앱 비밀번호를 만듭니다.
   계정 정책에 따라 앱 비밀번호가 지원되지 않을 수 있습니다. 일반 로그인 비밀번호는 사용하지 않습니다.
3. 프로젝트 폴더에서 다음 명령을 실행합니다.

   ```bash
   cd /data2/code/soribom
   .venv/bin/python scripts/setup_note_email.py
   ```

4. 발송용 Gmail 주소와 앱 비밀번호를 입력합니다. 비밀번호는 화면에 표시되지 않습니다.
   이 설정 과정에서는 메일을 보내지 않습니다.

설정은 `.email.local.ini`에 저장합니다. 권한은 600(소유자만 읽기·쓰기)이며 Git에서 제외됩니다.
앱 비밀번호를 채팅이나 커밋에 넣지 마세요. 계정을 바꾸거나 비밀번호를 갱신할 때도 같은 도구를 실행합니다.
새 패키지 설치는 필요 없습니다. Gmail SMTP는 `smtp.gmail.com:465`의 TLS 연결을 사용합니다.

## 수업 기록 보내기

1. 소리봄 상단 **노트 보내기**를 누릅니다.
2. 받는 이메일 주소 하나를 입력합니다. 주소는 저장하지 않습니다.
3. 읽기 전용 미리보기에서 보낼 기록을 확인합니다.
4. **보내기**를 누릅니다. 이메일 본문과 UTF-8 TXT 첨부에 같은 기록이 들어갑니다.
5. '메일 서버에 전송했습니다' 안내 후 받은편지함 또는 스팸함에서 확인합니다.

기록은 창을 연 시점에 고정됩니다. 창을 열어둔 동안 들어온 새 발화도 보내려면 닫았다가 다시 엽니다.
전송 중에는 중복 전송·닫기를 막지만 자막과 방향 처리는 계속됩니다.
현재 수업만 보낼 수 있고, 과거 파일 선택이나 내용 수정은 제공하지 않습니다.

## 문제가 생기면

- 계정 미설정: 위 설정 명령을 실행합니다. 앱을 다시 시작할 필요는 없습니다.
- 인증 실패: Gmail 주소·앱 비밀번호를 확인하고 설정 도구를 다시 실행합니다.
- 인터넷 연결 실패: 네트워크를 확인한 뒤 같은 창에서 다시 보냅니다. 자동으로 재시도하지 않습니다.
- 발송 여부 확인 불가: 서버가 이미 받았을 수 있으므로 메일함을 확인한 뒤 다시 시도합니다.
- 보안 연결 실패: 컴퓨터 날짜·시간과 네트워크를 확인합니다. 인증서 검증을 끄지 않습니다.

음성 녹음은 메일에 포함하지 않습니다. 사용자가 보낸 수업 기록 텍스트는 Gmail 서버와 수신자에게 전달됩니다.
메일 서버의 수락은 받은편지함 도착을 보장하지 않습니다. 인터넷이 없어도 기존 수업 기능은 계속 동작합니다.

## 팀 테스트

실제 메일 없이 자동 테스트:

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -v
```

실제 기기에서는 밝은/어두운 테마, 잘못된 주소, 인터넷 단절, 전송 중 자막·방향 갱신을 확인합니다.
전용 Gmail 설정 후 팀의 테스트 주소로 한 번 보내 본문과 TXT 첨부 수신을 확인하세요.
실제 수신 확인 전까지는 메일 발송 검증을 완료로 기록하지 않습니다.
