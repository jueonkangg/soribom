## 지연 감소 제안 (인식 설정은 아직 수정하지 않음)

1. 가장 간단한 조정은 발화 종료 무음 400→300ms다. 현재 32ms 창 때문에 실제 기준은
   416→320ms로 약 96ms 짧아진다. 최종 전체 지연 감소량은 추론 변동 때문에 보장하지 않는다.
   문장 중간 숨/짧은 멈춤에서 너무 잘리지 않는지 확인한다.
2. 말하는 동안 자막이 오래 안 뜨는 경우 최대 발화 길이 30→6~8초를 검토한다.
   발화 끝 지연과 별개의 체감 문제다. 문장/이름이 잘리는 부작용이 있어 8초부터 시작하고
   필요할 때만 경계 문맥 보존/중복 제거를 설계한다. 무조건 짧게 자르면 추론 횟수가 늘 수 있다.
3. 시작 시 STT 웜업을 모델 준비 단계에 넣어 첫 실제 발화의 초기 추론 부담을 옮긴다.
   준비 시간은 늘고 지속 사용 지연 개선은 기대하지 않는다. 웜업 출력은 게시/저장하지 않는다.
4. 전사 큐 삽입→추론 시작과 Qt 슬롯 도착 시각을 기록하면 실제 대기/화면 반영을 구분할 수 있다.
   다음 튜닝에서 재시도 횟수·VAD 비용도 함께 측정한다. CPU 스레드나 hotwords 변경은 이 근거 이후다.
5. 여전히 긴 꼬리 지연이 문제면 온도 재시도 제한·best_of 축소를 별도 비교한다.
   인식 정확도가 떨어질 수 있어 단순 속도 설정으로 즉시 적용하지 않는다.

추천 첫 단계는 400→300ms와 시작 웜업이다. 연속 발화가 주요 불편이면 8초 분할을 추가한다.
새 큐를 없애거나 이전의 음성 삭제 동작으로 되돌리지 않는다.

현재 요청은 스피커 연결 확인 → 진행 중인 STT 완료 대기 → 전체 문장 합성 → 출력 제출 순서다.
초기에는 공유 추론 게이트가 없었다. 게이트 대기는 추가 지연 후보지만, 동시에 STT/TTS를
실행하며 생긴 먹통·메모리 문제를 피하고 사용자가 요청한 순서를 지키므로 제거하지 않았다.
긴 문장은 전체 합성이 끝나야 재생되며 CPU 폴백·스피커 재연결도 지연 후보다.
실제 Bluetooth 전달 지연과 UI Enter→말하기 워커 시작 간격은 이번 시험으로 계측하지 않았다.

### 이번 수정

- 매우 작은 선행 잡음만 제거한다. 절대 진폭 0.0001(-80dB)을 넘는 첫 신호 앞에 60ms를
  보존하며, 제거량은 최대 200ms다. 50ms 미만의 제거는 생략하고 무음·빈 배열·비정상 수치는
  그대로 둔다. `tts.trim_leading_quiet: false`로 원복 가능하다. 유효한 작은 첫 자음을
  공격적으로 자르지 않도록 보수적으로 잡았으며, 실제 첫 음절 청취 확인은 별도로 필요하다.
- 기존 `tts_synthesis.duration_s`에는 연결 확인 시간이 섞여 있었다. 이제 합성만 측정한다.
  이전 로그와 이 지표를 그대로 비교하면 안 된다.
- `tts_output_ready`는 합성 전 연결 확인/재연결 시간, `tts_playback.output_prepare_s`는
  합성 완료→출력 제출 시간(앞부분 정리 포함), `leading_trim_s`는 제거된 음성 길이다.
  분석 스크립트도 이를 요약한다. 원문·음성·예외 메시지는 진단 파일에 넣지 않는다.
- 말하기 시작은 워커의 `Speaker.say` 진입이며, 재생 제출은 실제 스피커 첫 소리 시각이 아니다.

## 발화 방향에 따른 자막 문단 구분 — 2026-10-14

사용자 요청에 따라 jueon 브랜치에서 구현했다. 사용자는 같은 방향의 발화는 이어 붙이고,
직전 발화와 방향이 5° 이상 달라지면 새 문단으로 표시하는 방식을 선택했다.
각도 차이는 원형 최단 거리로 계산하므로 359°→1°는 2°다. 기준은
`ui.caption_direction_break_degrees: 5`로 조정한다. 기준은 직전 완료 발화이며 문단의
첫 발화가 아니다. 작은 변화가 누적되는 경우에도 각각 5° 미만이면 같은 문단이다.

방향 미확정·비정상 각도·장치 장애 중 발화는 별도 문단으로 표시하고 비교 기준을
초기화한다. 연결이 끊겼다 복구되면 같은 각도여도 새 문단부터 시작한다. 빈 전사 결과는
발화 비교 기준을 바꾸지 않는다. 30초 이상 공백의 빈 줄 구분은 유지한다.
방향 변화는 화자 신원 판별이 아니며 같은 화자의 이동도 문단을 나눌 수 있다.
5°는 잠정 기준으로 실제 마이크의 흔들림에 따른 분할 빈도는 실사용 확인이 필요하다.
