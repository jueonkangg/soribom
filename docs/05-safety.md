# 5. 안전·참가자 보호·개인정보 관리

## 실제 실시와 계획의 구분

최종 이해도 실험은 청각장애가 없는 성인 26명(대학생 24명·학부모 지인 2명)의 탐색적 비교다.
[실험 기준](04-experiment.md)을 따른다. 초기 계획의 동급생·보호자 동의·마스킹·무작위 순서를 실제 실시로 설명하지 않는다.

- 사전 퀴즈 목표 정답률은 **40~70%**였다. 전원의 개별 달성 검증이나 동일한 차음 상태의 보장은 아니다.
- 귀마개·ANC 등의 사용 종류·차음 정도를 참가자별로 충분히 기록하지 않아 실제 난청을 재현했다고 볼 수 없다.
- 참가자의 자발적 참여·중단 안내·동의서와 자료 보관 상태는 원 문서로 확인한다. 성인 참여자를 미성년자로 설명하거나 보호자 동의를 모두 받았다고 추정하지 않는다.

## 출력·청력 안전의 현재 범위

- 현재 TTS 출력은 Bose Bluetooth 스피커다. 실제 보청기·인공와우에 우리가 만든 소리를 직접 보내는 실험은 하지 않는다.
- 낮은 음량부터 확인하고 불편하면 중단한다. 일반 스피커도 과도한 음량에 대한 관리가 필요하다.
- 교사 음성의 보청기 직접 전달과 청력 보호용 AGC·세이프티 리미터는 구현·검증 완료된 기능으로 주장하지 않는다.
- 모든 실험에서 디지털 소음계로 음량을 확인했다는 근거는 현재 최종 보고서에 없으므로 완료 사실로 쓰지 않는다. 후속 평가에서는 측정 조건을 기록한다.

## 전기·설치

- 동봉 Jetson 어댑터와 모니터 USB-C 전원을 구분한다. Jetson 전원은 다른 선을 연결한 뒤 마지막에 연결한다.
- 배선·분해 작업은 전원을 분리한 뒤 진행한다. 팬 통풍구가 위를 향하고 막히지 않도록 둔다.
- Bose USB는 충전용이며 음성은 Bluetooth다. 자세한 연결은 [프로젝트 안내](../README.md)를 참고한다.

## 기록과 개인정보

- 핵심 음성 처리는 로컬이며 자동으로 음성을 서버에 보내지 않는다. 사용자가 미리보기·주소 확인 후 실행하는 이메일은 전사 텍스트를 외부 전송한다.
- 바탕화면 수업 TXT는 전사 원문과 사적 발화를 포함할 수 있다. 파일 권한 600은 암호화나 같은 계정 사용자에 대한 접근 차단이 아니다.
- 진단 로그에는 음성·전사 원문·비밀번호를 넣지 않는다. 실험 식별정보·서명·연락처·개인별 점수는 Git에 추가하지 않는다.
- 보관·삭제·반출 정책은 별도 관리하며 자동 삭제나 특정 화자만 저장하는 기능이 구현됐다고 주장하지 않는다.
- 대회 공개 자료의 이름 비기재 요구는 사용자가 전달한 범위에 따라 최종 확인한다. 시연은 가명 김민수·민수를 사용할 수 있으나 기존 실명 자막·파일명·기록 노출 여부도 점검한다.
