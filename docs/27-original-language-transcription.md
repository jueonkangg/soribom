# 영어 발화의 원문 전사 — 2026-10-13

최신 사용자 선택: **영어 과목에서만 한국어/영어 자동 감지**, 국어·수학·과학·경제에서는
한국어 고정이다. 화면의 과목 선택을 바꾸면 다음 전사부터 적용되며 모델은 재로딩하지 않는다.
전사 도중 과목을 바꿔도 이미 시작한 발화의 언어 설정은 유지한다.
나머지 과목에서는 언어 감지를 실행하지 않으므로 감지로 인한 추가 지연도 없다.
아래의 전 과목 자동 감지 시험은 이 제한을 추가하기 전 결과다.

## 문제와 변경

사용자는 영어로 말해도 영어 자막 대신 한국어로 바뀌는 현상을 보고했다.
코드에 별도 번역기는 없었지만 STT의 `language`가 `ko`로 고정되어 있었다.
실제 모델 시험에서도 이 조건에서 영어 문장이 한국어로 출력되는 현상을 재현했다.

`src/config.yaml`의 STT 언어를 `auto`로 바꾸고, 각 VAD 발화마다 언어를 감지하게 했다.
후속 사용자 요청으로 감지 확률 중 **한국어(ko)·영어(en)만 비교**해 높은 쪽을 전사 언어로
전달한다. 다른 언어가 전체 감지 확률에서 1위여도 전사 후보에는 포함하지 않는다.
`ko`/`en` 고정 설정도 허용하고 다른 언어 고정 설정은 오류로 안내한다.
`task="transcribe"`도 명시했다.
이 task는 기존 라이브러리 기본값과 같으며, 핵심 변경은 한국어 고정을 해제한 것이다.
이전 발화 문맥은 계속 사용하지 않아 한국어/영어가 교대로 나와도 발화마다 감지한다.
모델·beam·hotwords·신뢰도 필터·오프라인 처리 방식은 유지한다.

라이브러리의 언어 감지와 task 인자는 설치된 faster-whisper 1.2.1 코드와
[공식 전사 코드](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/transcribe.py)에서 확인했다.

## 검증

최초 변경의 전체 자동 테스트 **105개 통과(10.345초)**. 후속 두 언어 제한은
발화별 선택·원문 task·제외 언어의 확률 무시·고정 언어의 감지 생략·설정 검증을 추가했다.
후속 전체 테스트 **107개 통과(10.822초)**. 같은 실제 GPU 시험 음성 4개에서도
선택 언어가 en/ko/en/ko로 일치하고 원문 전사가 유지됐다. 전사 시간은
각각 1.492/1.136/1.011/0.967초였다. 첫 호출에는 초기 실행 비용이 포함된다.
이 브랜치에는 stash에 보관한 입력창 수정이
포함되어 있지 않으므로 앞선 guhyeon 로컬의 108개 테스트와 기준이 다르다.

기존 오프라인 Supertonic으로 한국어/영어 시험 음성 4개를 합성하고, 같은 오디오를
실제 GPU small 모델의 `ko`/자동 설정에 각각 입력했다. 참가자 녹음은 사용하지 않았다.

| 시험 입력 | 한국어 고정 출력 | 자동 감지 출력 |
|---|---|---|
| Teacher, I have a question. | 선생님, 질문을 드릴게요 | Teacher, I have a question. |
| Good morning, everyone. Today we will learn about photosynthesis. | 좋은morning everyone, today we will learn about photosynthesis | Good morning everyone, today we will learn about photosynthesis. |
| 안녕하세요 여러분. 오늘은 광합성을 배워보겠습니다. | 한국어 유지 | 한국어 유지 |
| 선생님, 질문이 있어요. | 한국어 유지 | 한국어 유지 |

시험 음성과 계산 결과는 `/tmp/soribom-language-clips.npz`, `/tmp/soribom-language-test.json`에
보관했다. 합성·인식 모델을 동시에 유지한 최초 시험에서는 CUDA 메모리 부족으로 실패했다.
최종 비교는 합성 프로세스를 종료하고 인식 모델만 실행한 상태에서 완료했다.
이 실패를 언어 설정 때문이라고 단정하지 않으며 실제 앱 동시 상주 안정성은 별도 검증이 필요하다.

## 한계와 사용 확인

언어 감지에는 추가 시간이 든다. 한국어 시험 2개의 전사 시간은 고정 설정 0.646/0.593초,
자동 설정 1.138/0.998초로 약 0.4~0.5초 늘었다. 이는 소수의 합성 음성 시험이며
실제 UI 지연이나 전체 수업 평균으로 일반화하지 않는다.

발화마다 감지하므로 짧고 불분명한 소리, 외래어, 한 발화 안에서 언어가 섞이는 경우의
정확도는 보장하지 않는다. 마이크에서 실제 발음/억양을 포함한 재시험이 필요하다.
이는 전사 언어 선택의 제한이며 모델 자체에서 나머지 언어의 가중치를 제거한 것은 아니다.
앱을 다시 실행하고 영어 문장→한국어 문장→영어 문장 순서로 말해 원문 표시를 확인한다.
TTS의 발화 언어는 이번 변경 범위에 포함되지 않는다.

작업은 최신 main을 반영한 로컬 doyu에서 진행했다. 아직 커밋/푸시하지 않았고,
기존 두 stash와 진단 기록은 보존했다.
