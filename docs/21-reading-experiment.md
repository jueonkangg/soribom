# 젊은이의 시절 장시간 낭독 시험 준비

2026-10-12. 사용자가 제공한 위키문헌 원문과 LibriVox MP3 2개로 스마트폰 재생 시험을 준비했다.
진단·작품 사전 작업은 현재 guhyeon의 커밋·푸시 전 변경이다.
본시험 분석은 [낭독 시험 결과](22-reading-experiment-results.md)에 기록했다.

## 자료와 조건

- 원문: https://ko.wikisource.org/w/index.php?title=젊은이의_시절&oldid=120347
- 녹음: https://archive.org/details/short_stories_na_1412_librivox
- 1부 `shortstories_1_na_128kb.mp3`: 27분 57.636초.
- 2부 `shortstories_2_na_128kb.mp3`: 23분 48.558초.
- 합계 51분 46.194초. 다운로드 MD5를 Archive 메타데이터와 대조했고 ffprobe로 시간을 확인했다.
- 자료는 `experiments/data/reading_2026-10-12/`에 권한 600·Git 제외로 보관했다.
  `manifest.json`에 출처·원문 revision·파일 해시·시간·인식 설정을 기록했다.
- 스마트폰 재생은 반복 가능한 연속 입력 시험이며 실제 교실의 다화자·방향 정확도 시험과 구분한다.

## 사용자 선택에 따른 수업 사전

사용자가 어려운 단어를 hotwords에 넣도록 요청해 `src/vocab/young_days.txt`에
원문에서 확인한 인물명·드문 어휘 24개를 등록했다. 예: 조철하·경애·영빈·최면제·
오뇌·천애·가극·악극·종려나무·금강석. 작품의 문장 전체를 힌트에 넣지는 않는다.

`stt.subject=korean`, `stt.lesson_vocab.korean=young_days`로 이번 시험을 준비했다.
다른 과목에는 작품 사전을 적용하지 않는다. 일반 국어 수업으로 돌아갈 때는
lesson_vocab의 korean 항목을 지운다. 설정은 시험 시작 전에 정하고 중간에 변경하지 않는다.

등록 학생 이름/호칭→작품 용어→일반 과목/공통 교대 순으로 토큰 한도 안에서 선택한다.
실제 small 토크나이저로 163개 후보 중 61개·223토큰을 확인했고 작품 용어 24개와
기본 이름/호칭 8개 모두 포함됐다. 전체 88개 테스트 통과(8.521초).

결과는 **수업 자료의 어휘를 미리 제공한 조건**으로 보고한다. 사전 없는 조건이나
처음 보는 어휘의 기본 인식 정확도라고 표현하지 않는다. 이후 대조 시험을 할 경우
같은 녹음·위치·볼륨·속도에서 lesson_vocab만 제거한 별도 세션으로 비교한다.

## 비교 텍스트와 제외 규칙

`reference_original.txt`는 본문만 추출했고 원문 HTML도 별도 보존했다.
`reference_normalized.txt`는 아래 규칙의 분석용 초안이다. 오디오와 정답 텍스트의
완전한 일치 여부는 아직 확인하지 않았으므로 그대로 확정 정답으로 간주하지 않는다.

1. Unicode NFC로 통일한다.
2. 한자/공백만 들어 있는 괄호 병기 20개를 제거한다. 일반 괄호 설명을 통째로 지우지 않는다.
3. 인용부호·문장부호를 공백으로 바꾸되 따옴표 안의 대사는 그대로 남긴다.
4. 연속 공백을 정리한다. CER는 공백 제외, WER는 정리한 공백의 단어 기준으로 계산한다.
5. 제목·부 제목·LibriVox 소개/마무리는 실제 오디오와 대조해 본문 점수에서 분리한다.
   시간 위치를 확인하기 전에 고정 초 단위로 잘라내지 않는다.
6. 원문의 옛 표기·띄어쓰기·숫자와 낭독 차이는 별도 검토한다. 인식 결과에 맞춰 정답을
   임의로 고쳐 오류율을 낮추지 않는다. 정답 변경이 필요하면 원음 근거와 규칙을 기록한다.

## 진행과 분석

1. 앱을 완전히 종료·재실행하고 과목이 국어인지 확인한다. 스마트폰은 1배속,
   동일한 위치·볼륨에 고정하고 알림을 끈다.
2. 1부→2부를 한 앱 세션에서 순서대로 재생한다. 시작·1부 종료/2부 시작·일시정지 시각을 적는다.
3. 본시험 중 말하기·마이크 분리는 하지 않는다. 동시 사용·재연결 안정성은 별도 시험으로 구분한다.
4. 끝난 뒤 약 10초 기다리고 앱을 정상 종료한다. 이상 증상의 시각도 알려준다.
5. 진단 로그와 해당 수업 TXT를 대조하고 전체/구간별 정확도·지연·메모리·누락을 분석한다.
   현재 수업 TXT에는 발화별 시각이 없으므로 5분별 CER를 확정하려면 오디오-텍스트 정렬이
   추가로 필요하다. 진단 이벤트 순서만으로 각 문장의 정답 시각을 단정하지 않는다.

진단 로그에는 원문이 없으므로 인식 정확도를 그것만으로 계산할 수 없다.
정확도는 수업 TXT와 실제 낭독 정답으로, 자원·처리 오류는 진단 로그로 판단한다.
