## 1. 촬영 준비

### 1-1. 인물 배치도 (방향 시연의 핵심)
기기(소리봄)를 **책상 중앙**에 두고, 그 앞에 **기기를 쓰는 학생(주인공) = 함도유**가 앉는다.
나머지 **두 학생(선생님 역 강구현·친구 강주언)이** 발화한다. **지도교사(임성원)는 촬영 담당(화면 미등장).** 출연·대사는 `시연영상-대본.md` 참조.

```
                 [앞 0°]  강구현(선생님 역)
                     │
 [왼쪽 270°] (강주언 이동) ──┼── 강주언 [오른쪽 90°]
                     │        (강주언: 오른쪽→왼쪽→뒤로 이동)
                 [뒤 180°] (강주언 이동)
                     ·
           (중앙) 함도유 + 소리봄 기기
     ※ 지도교사(임성원)는 카메라 뒤 — 화면에 나오지 않음
```
- **방향 = 강구현(선생님)이 ‘앞’ 고정**, 나머지 **오른쪽·왼쪽·뒤는 강주언이 자리를 옮겨** 별도 테이크로 찍어 편집에서 이어 붙인다(화면 출연이 학생 셋뿐).
- ⚠️ **방향 시연 시 정확한 각도에 서기**(마이크 보드 LED로 실제 방향 확인). 마이크(케이스) 윗면(LED)이 보이게 둘 것. 오차 1.5°는 이 조건.

### 1-2. 장비
- **카메라 1대(상황용)**: 스마트폰이면 충분. 삼각대 고정. 배치도가 다 보이는 **약간 높은 각도**.
- **화면 녹화(스크린 캡처)**: 자막·화살표가 **선명하게** 나오도록 소리봄 화면을 직접 녹화.
  - 방법 A(권장): 소리봄 프로그램 화면을 **화면 녹화 소프트웨어**로 캡처.
  - 방법 B(대안): 카메라로 **모니터를 정면 클로즈업**한 별도 컷을 찍어 사용.
- **음성**: 카메라 내장 마이크로 현장음(사람 말·**TTS 스피커 소리**) 녹음. TTS가 또렷이 들리게 **스피커 볼륨 확인**.

### 1-3. 촬영 원칙
- **여러 번 찍는다.** 실시간 기능이라 한 번에 안 될 수 있음 → **가장 깔끔한 테이크** 사용(대회 규정상 편집 허용).
- **자막이 튄 테이크는 버린다**(과목을 대사에 맞게 선택해 예방).
- 데모 전 **브라우저 등 무거운 프로그램 끄기**(메모리·GPU 안정).

## 2. 컷별 상세 콘티

> 각 컷: **화면(무엇이 보이나) / 촬영법 / 온스크린 자막(노란=제목·흰=접근성 대사자막) / 현장음**
> (등장인물이 실제 하는 말/대사는 `시연영상-대본.md` 참조 — 여기엔 넣지 않는다)

### 컷 1 — 문제 (0:00–0:12)
- **화면**: 교실. 선생님(강구현)과 친구(강주언)가 **동시에 웅성웅성** 말한다(질문·잡담·이름 부름 뒤섞임). 카메라가 서서히 **중앙 학생**으로 다가가고, 소리가 **먹먹하게 뭉개지며** 학생은 두리번거린다(누가 말하는지 못 찾는 표정).
- **촬영법**: 상황 카메라. 학생 얼굴 쪽으로 천천히 줌인. 편집에서 이 구간만 **소리를 먹먹하게(로우패스)** 처리해 “안 들리는 느낌”.
- **온스크린 자막**: (흰, 하단) 실제 말들 “질문 있어요” “몇 쪽이야?” “도유야!” 가 겹쳐 뜸 → (노랑, 중앙) **“누가, 어디서, 무슨 말일까?”**
- **현장음**: 웅성거림(먹먹하게).

### 컷 2 — 소리봄 등장 (0:12–0:18)
- **화면**: 학생이 책상 중앙의 **소리봄 화면을 켠다**. “소리봄 준비 완료 — 말하면 자막이 나옵니다”가 뜬다. 로고 **“소리봄 / SoundSight”**.
- **촬영법**: 기기+화면 클로즈업(화면 녹화 컷). 먹먹하던 소리가 이 순간 **또렷하게 열린다**(오디오 회복).
- **온스크린 자막**: (노랑) **“소리봄 — 소리를 눈으로 보다”**
- **현장음**: 켜지는 소리 + 또렷해진 교실.

### 컷 3 — ① 실시간 자막 (+ 과목 선택) (0:18–0:42)
- **화면**: 먼저 헤더의 **‘과목’ 드롭다운에서 ‘경제’를 고른다**(짧게 클로즈업). 이어 강구현(선생님)이 **“오늘은 수요와 공급에 대해 배워 볼게요. 가격이 오르면 수요량은 줄어듭니다”** 라고 또박또박 말하고, 화면 하단에 **그 문장이 자막으로** 뜬다. 주변이 조금 **시끄러운 상황**에서도 정확히 나온다.
- **촬영법**: **과목 드롭다운 선택 → 화면 녹화(자막 클로즈업)** + 말하는 교사 상황 컷 **교차 편집**.
- **온스크린 자막**: (노랑, 상단) **“① 실시간 자막 · 과목별 용어 사전 · 완전 오프라인”** / (흰) 인식된 자막 그대로.
- **현장음**: 교사 목소리 + 약한 소음.
- 📌 **포인트**: “과목을 고르면 그 과목 용어에 맞게 정확해진다”가 보이게(경제 선택 → ‘수요·공급’ 정확).

### 컷 4 — ② 누가·어디서 (+ 이름 호명 알림) (0:42–1:18) ★하이라이트
- **화면**: 화면 위쪽 **방향 나침반**을 중심으로. 순서대로 말할 때마다 **파란 화살표가 그 방향**을.
  1. **앞(강구현/선생님, 0°)** “자, 이 그래프를 한번 볼까요.” → 화살표 **위(12시)**
  2. **오른쪽(강주언, 90°)** “선생님, 저 질문 있어요!” → 화살표 **3시**
  3. **왼쪽(강주언 이동, 270°)** “그럼 공급이 늘면 가격은 어떻게 돼요?” → 화살표 **9시**
  4. **뒤(강주언 이동, 180°)** “저는 뒤에서도 잘 보여요.” → 화살표 **6시** (별도 테이크)
  - 그리고 **선생님(강구현)이 “도유 학생?” 하고 이름을 부르면** → 화면에 **주황 배너 “🔔 도유 학생을 불렀어요”**가 잠깐 뜬다. 중앙 학생이 **알아채고 반응**한다.
- **촬영법**: **화면 녹화(화살표·알림 배너 클로즈업)** 와 **말하는 사람(상황 컷)** 을 **좌우 분할 또는 빠른 교차**로. “이 사람 말함 → 화살표 그쪽”, “이름 부름 → 알림” 대응이 **한눈에**. 각 방향 약 5–6초 + 이름 알림 4초.
- **온스크린 자막**: (노랑, 상단) **“② 누가·어디서 — 화자 방향 + 이름 호명 알림”** / 각 방향에 **“앞/오른쪽/뒤/왼쪽”** 라벨 / 하단 작게 **“평균 오차 1.5°”**.
- **현장음**: 각자의 짧은 발화 + 이름 부르는 소리.

### 컷 5 — ⑥ 말하기 (1:18–1:40)
- **화면**: 중앙 **학생이 입력칸에 타이핑**: **“저는 균형가격이 수요와 공급이 만나는 점이라고 생각해요.”** → **엔터**. 잠시 후 **스피커에서 또렷한 목소리**로 발화. 강주언과 선생님(강구현)이 **소리 나는 방향(학생)을 바라본다.**
- **촬영법**: 타이핑하는 손·화면(화면 녹화) → 엔터 → 스피커 쪽 컷 → 사람들이 학생을 보는 반응 컷. **TTS 목소리가 반드시 또렷하게.**
- **온스크린 자막**: (노랑, 상단) **“⑥ 양방향 말하기 — 타이핑을 목소리로”** / (흰) 발화되는 문장 자막.
- **현장음**: 타이핑 소리 + **TTS 발화(핵심)**.

### 컷 6 — 오프라인 증거 (1:40–1:52)
- **화면**: **와이파이를 끄는 화면(✈️/‘연결 끊김’)** 클로즈업. 그 상태에서 다시 **말하면 자막, 화살표가 돌고, 타이핑하면 발화**되는 짧은 몽타주.
- **촬영법**: 와이파이 OFF를 명확히 클로즈업 → 세 기능이 그대로 도는 3–4개 짧은 컷.
- **온스크린 자막**: (노랑, 중앙) **“인터넷 없이 — 음성이 기기 밖으로 나가지 않습니다”**
- **현장음**: 그대로.

### 컷 7 — 수업 기록 + 마무리 (1:52–2:00)
- **화면**: 헤더 **‘수업 기록 보기’** 를 눌러 **팝업에 지금까지의 발화가 쭉 기록된 것**을 짧게 보여 준다(1~2초) → **학생의 옅은 미소/안도** → 화면 전환으로 **측정 지표** → 슬로건.
- **촬영법**: 수업 기록 팝업 클로즈업(스크롤) → 학생 클로즈업 → 지표 자막(모션) → 로고/슬로건.
- **온스크린 자막**:
  - (팝업 위, 작게) **“⑤ 수업 기록 — 모든 발화를 그대로 저장”**
  - **자막 실사용 3.2%**(조용할 땐 0%대) · **자막 지연 0.6초** · **방향 1.5°** · **말하기 1.8초**
    - ⚠️ **‘0.0%’를 단독 헤드라인으로 띄우지 말 것.** 대표값은 실사용 3.2%. (0%대는 통제 조건 값)
  - (노랑, 대) **“소리봄 — 교실의 모든 소리를, 눈으로 보고 목소리로 전한다”**
- **현장음**: 잔잔하게 페이드아웃.

## 3. 편집 가이드

- **화면 녹화 + 상황 컷 합치기**: 자막·화살표는 **화면 녹화(선명)**, 사람·상황은 **카메라 컷**. 방향(컷4)은 **좌우 스플릿**이 가장 효과적(사람 ↔ 화살표 동시).
- **온스크린 자막 2종**:
  - **노랑(제목·라벨)**: 기능 이름·핵심 문구. 크게, 3–4초 이상 노출.
  - **흰(대사 자막)**: 등장인물 대사 + TTS 발화 내용 → **이 영상을 소리 없이도 이해**할 수 있게(청각장애 주제에 걸맞는 배려이자 강점).
- **가독 속도**: 자막은 **읽을 시간**을 준다(한 화면 2초 이상). 컷을 너무 빨리 넘기지 않기.
- **오디오**: 컷1만 먹먹하게, 컷2부터 또렷하게(대비). **TTS 발화(컷5)는 절대 음악에 묻히지 않게.**
- **길이**: 제출본 **2:00 이하** 확인. + 발표용 **60초 클립**(컷3·4·5)도 따로 뽑기.

## 4. 촬영 당일 체크리스트

- □ **화면에는 학생 3명만** — 지도교사(임성원)는 촬영 담당(미등장), 그 외 제3자 노출 금지
- □ **마이크 윗면(LED) 노출** + 방향 시연 시 **정확한 각도에 서기**(LED로 확인, 오차 1.5°의 조건)
- □ 무거운 프로그램 종료(메모리·GPU 안정)
- □ 스피커(블루투스) 연결·볼륨(TTS 또렷하게)
- □ **과목 선택**(드롭다운)을 대사에 맞게 — 이번 강의는 ‘경제’ 선택(수요·공급 정확)
- □ 위치(앞/오/뒤/왼) 바닥 표시 — 강주언은 오른쪽·왼쪽·뒤 세 자리 이동
- □ 삼각대 고정, 배치 전체가 보이는 각도
- □ 화면 녹화 준비(또는 모니터 클로즈업 대체 컷)
- □ 각 기능 **여러 테이크** 촬영, 자막 틀린 것 제외
- □ 와이파이 OFF 컷 확보(오프라인 증거)
- □ 편집 후 **2:00 이하** + **60초 발표용 클립** 확보
