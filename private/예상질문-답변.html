Jetson의 GPU를 주 실행 경로로 사용합니다. 약 1.8초는 과거 특정 문장의 합성 시간이지 모든 문장의 Enter→실제 소리 지연이 아닙니다. CPU 폴백은 모델 초기화 단계에 적용하며, 실행 중 모든 GPU 오류를 자동 복구하는 기능은 아닙니다. CPU 32스텝은 느리고 CPU 초기화도 실패할 수 있어 화면의 재시도와 상태 안내가 필요합니다.
